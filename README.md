# Ajmal Abbas Portfolio — Version 1

A recruiter-facing personal portfolio for Ajmal Abbas, focused on AI/ML, data science, scientific AI, research, and engineering work.

## Files
- `index.html` — website content and structure
- `styles.css` — design, responsive layout, aesthetic backgrounds, animations
- `script.js` — navigation and scroll reveal interactions
- `Ajmal_Abbas_Resume.pdf` — current resume used by the Resume button

## Deploy
This site is static and can be deployed to Cloudflare Pages, GitHub Pages, Netlify, or Vercel.
